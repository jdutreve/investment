# Skill — compare a challenger against the defender

> **RETAINED BRIDGE (ADR-007).** The ranked defender/challenger duel is no
> longer the live allocation decision — the market-signal monthly stack is. No
> live cycle emits a switch. This comparison is kept as BENCHMARK commentary:
> it tells the owner how the retained fallback book is faring against its
> alternatives, which is what makes the fallback trustworthy if it is ever
> needed.

**Purpose.** Challenger gaps and downside-profile flags, folded into
`reasoning`.

**Method.** Report the Sortino gap, the Calmar standing and the shape of the
downside — a challenger that leads on return while drawing down harder is not
leading. Name the regime the challenger was designed for and whether it is the
one we are in.

Write it as commentary, not as a recommendation to switch.
